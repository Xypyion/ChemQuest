# คู่มือการใช้งานสำหรับนักเรียน (Student Guide)

ยินดีต้อนรับสู่ **ChemQuest** การผจญภัยเรียนรู้วิชาเคมี! 🧪

## เริ่มต้นใช้งาน
1. เปิดเว็บไซต์ที่ `http://localhost:4000`
2. กดแท็บ **สมัครสมาชิก** แล้วกรอกชื่อ อีเมล และรหัสผ่าน (อย่างน้อย ๖ ตัวอักษร)
3. เลือกระดับความยากที่ต้องการ: **ง่าย / ปานกลาง / ยาก**
4. กด **สร้างนักสำรวจ** เพื่อเริ่มเล่น
5. สลับภาษาไทย/อังกฤษได้จากปุ่ม **EN | ไทย** ที่มุมขวาบน

## แผนที่การผจญภัย 🗺️
- คุณจะเดินทางผ่าน ๓ ภูมิภาค: **ทุ่งหญ้า → หุบเขาถ่านไฟ → ยอดฟ้า**
- แต่ละด่านจะปลดล็อกทีละด่าน ด่านที่เล่นได้จะมีตัวการ์ตูนโบกมือ พร้อมป้าย “แตะเพื่อเล่น!”
- ด่านที่ล็อกอยู่จะมีสัญลักษณ์ 🔒 (แตะเพื่อดูเหตุผลว่าทำไมยังเข้าไม่ได้)

## เมื่อแตะที่ด่าน — กระดานประจำด่าน
ด้านบนมี ๓ แท็บ: **🏠 กระดาน · 📒 ส่งงาน · 🧩 โจทย์** และในกระดานจะพบเมนู
1. **📖 เนื้อเรื่อง** — อ่านเรื่องของรูบี้และดูวิดีโอ
2. **❓ แบบทดสอบก่อนเรียน** — ตอบคำถามของด่านนี้
3. **📒 ส่งงาน** — โพสต์ผลงาน ดูงานของเพื่อน และพูดคุยกัน
4. **🧩 โจทย์** — โจทย์ที่คุณครูมอบหมายให้
5. **🧾 แบบทดสอบหลังเรียน** — จะเปิดให้ทำเมื่อคุณครูเปิด

> **เนื้อเรื่องกับแบบทดสอบก่อนเรียนเป็นคนละกิจกรรมกัน** คุณครูเป็นผู้เลือกว่าจะให้ทำอะไรก่อน
> อีกกิจกรรมจะขึ้นรูปกุญแจ 🔒 จนกว่าจะทำกิจกรรมแรกเสร็จ
> ข้อความบนกระดานจะบอกว่าคุณครูให้เริ่มจากอะไร

## การเรียนและการทำแบบทดสอบ
- อ่านเนื้อเรื่องของรูบี้ทีละหน้า กด **ถัดไป ▶** หรือ **ข้ามเนื้อเรื่อง**
- ดูวิดีโอที่แทรกอยู่ในเนื้อเรื่อง
- ทำแบบทดสอบ: แตะเลือกคำตอบ ระบบจะบอกทันทีว่าถูกหรือผิด พร้อมคำอธิบาย
- หากมี **ตัวจับเวลา** ให้รีบทำให้ทัน เมื่อหมดเวลา ระบบจะบันทึกคำตอบล่าสุดให้
- ทำคะแนนได้ตั้งแต่ **๖๐%** ขึ้นไป จะ **ผ่าน** และได้รับ **เกียรติบัตร** 🎖️

## การปลดล็อกด่านถัดไป
- การผ่าน **แบบทดสอบก่อนเรียน** จะได้เกียรติบัตร แต่ยังไม่ปลดล็อกด่านถัดไป
- ต้อง **ผ่านแบบทดสอบหลังเรียน** (ที่คุณครูเปิดให้) จึงจะปลดล็อกด่านถัดไป

## โจทย์ (Challenges) 🧩
- แท็บ **🧩 โจทย์** รวมโจทย์ที่คุณครูมอบหมายให้ แยกตามหมวดหมู่
- แต่ละใบบอก **จำนวนข้อ คะแนนเต็ม กำหนดส่ง** และสถานะ
  (ยังไม่ได้เริ่ม / ส่งแล้วรอตรวจ / ตรวจแล้วพร้อมคะแนน)
- คำถามมีหลายแบบ: เลือกตอบข้อเดียว เลือกหลายข้อ ตอบสั้น เขียนย่อหน้า
  **เติมตาราง** และ **แบบจำลอง** — ให้ลองเล่นกับแบบจำลองก่อน แล้วตอบคำถามด้านล่าง
- ถ้ามีตัวจับเวลา ให้รีบทำให้ทัน เมื่อหมดเวลาระบบจะส่งคำตอบให้อัตโนมัติ
- กด **ส่งคำตอบ ▶** เมื่อพร้อม (ปกติส่งได้ครั้งเดียว เว้นแต่คุณครูอนุญาตให้ส่งซ้ำ)
- ข้อที่ระบบตรวจได้เองจะรู้คะแนนทันที ส่วนข้อเขียนต้องรอคุณครูตรวจ
  แล้วกลับมาดูผลและคำแนะนำได้ที่โจทย์เดิม

## กระดานส่งงาน 📒
- โพสต์ผลงานของคุณ พร้อมแนบไฟล์ได้: รูปภาพ, PDF หรือไฟล์ใดก็ได้ (สูงสุด ๖ ไฟล์ ไฟล์ละ ๘ MB)
- รูปภาพจะแสดงตัวอย่างให้เห็นทันที
- กด **❤️ ถูกใจ** และ **แสดงความคิดเห็น** ผลงานของเพื่อนได้
- ใต้โพสต์ **งานที่มอบหมายของคุณครู** จะมีช่อง **“นักเรียนสงสัยอะไรมั้ย”**
  ใช้ถามคุณครูแบบส่วนตัว — **มีเพียงคุณครูเท่านั้นที่เห็นข้อความนี้**

## ภารกิจประจำวัน ⚔️ และเหรียญ 🪙
- กดปุ่ม **⚔️ ภารกิจ** ด้านบนเพื่อดูภารกิจที่คุณครูมอบหมาย
- ตอบคำถามให้ถูกเพื่อรับ **เหรียญ** ยิ่งตอบถูกมาก ยิ่งได้เหรียญมาก
- ภารกิจหนึ่งทำได้ครั้งเดียว และบางภารกิจมีกำหนดเวลาเปิด–ปิด
- จำนวนเหรียญของคุณแสดงอยู่มุมบนขวาของทุกหน้า

## ประลองเหรียญ 🤺
- กดปุ่ม **🤺 ประลอง** เพื่อเข้าสนามประลอง
- ขั้นตอน: **เลือกระดับความยาก** → **เลือกเพื่อนที่จะท้า** → **ตอบคำถาม**
- ถ้าตอบถูก **ทุกข้อ** คุณจะได้เหรียญตามที่เดิมพันไว้จากเพื่อน
  ถ้าตอบผิด คุณต้องจ่ายเหรียญจำนวนเท่ากันให้เขา
- ระดับยิ่งยาก เดิมพันยิ่งสูง
- ถ้ามีการจับเวลา ต้องตอบให้ทันก่อนหมดเวลา ไม่อย่างนั้นจะนับว่าแพ้
- ประลองคนเดิมซ้ำต้องเว้นระยะสักครู่ และวันหนึ่งประลองได้ตามจำนวนที่คุณครูกำหนด
- เพื่อนที่ไม่มีเหรียญเหลือแล้วจะประลองด้วยไม่ได้ และเหรียญของใครก็ไม่มีทางติดลบ
- ด้านล่างมีประวัติการประลอง ทั้งครั้งที่คุณไปท้าเขา และครั้งที่เขามาท้าคุณ

## รางวัลและอันดับ
- **🎖️ เกียรติบัตร** — สะสมได้จากทุกด่านที่ผ่าน ดูได้ที่เมนูเกียรติบัตร
- **🏆 กระดานคะแนน** — เก็บคะแนนจากการทำแบบทดสอบเพื่อไต่อันดับกับเพื่อน ๆ

ขอให้สนุกกับการผจญภัยเรียนรู้เคมี! 🚀
